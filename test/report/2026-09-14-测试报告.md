## 四、E2E 套件覆盖要点

### 4.1 i18n 与 SEO（8 条全通过）

- 根路径 `/` 的 `title` / `description` / `canonical` / `hreflang` / `og:locale` 均为服务端实渲染结果，直接落在 DOM 上（非仅存在于打包产物）。
- `/en`、`/zh-Hant` 前缀路由下 `html lang`、`title`、`canonical` 全部随语言切换；语言切换交互后 URL、标题与正文文案同步，且可回退到繁体。
- `/zh-CN` 前缀按配置返回 404，`robots.txt` 与 `sitemap.xml` 可访问且指向站点域名。

### 4.2 安全（9 条，8 通过 + 1 预期失败）

- `description` 中的 `script` / `img onerror` 载荷被净化，不产生执行副作用；JSON-LD 中注入 `</script>` 无法逃逸，结构仍可正常解析。
- 页脚与歌单外链均带 `rel="noopener"`，无伪协议 `href`；服务端源码与配置文件不可经 HTTP 访问。
- API 边界：`GET /api/concerts/:id` 非数字返回 400、不存在返回 404；`POST /api/like` 非法载荷返回 400、目标不存在返回 404；`GET /api/data` 未知语言回退默认语言。
- **预期失败**：`public/data/data.db` 可经 HTTP 直链下载（见 §5.2）。

### 4.3 UI 结构与静态资源（10 条全通过）

- hero 区站点名 / 副标题 / 角色标签完整；相册详情面板的标题、日期、时间轴条目字段非空；点击相册卡片可切换选中态，详情标题随之变化。
- 站点主图、背景音乐、演唱会图片等静态资源均返回 200；首页样式表加载成功且同源资源无失败请求。
- 语言下拉点击展开（3 个语言项）、点击空白处或按 Esc 收起；背景音乐按钮可在 `.playing` 播放态与暂停态之间切换。
- 页脚品牌区与社交外链正常渲染（三种语言的 tagline 在数据层即为有意留空，非缺陷）。

### 4.4 UE 交互（11 条全通过）

- 首屏 loader 展示后收起，主内容与统计卡片正常渲染；列表与卡片按 fixture 数量渲染，有数据时不显示空态。
- 点赞：单击生效、状态高亮、**仅发送 1 次请求**（防连点）、刷新后计数持久化、可再次取消；点赞数进入前三档的场次显示热点徽标，0 赞场次不显示。

## 五、发现的缺陷

### 5.1 已修复：移动端横向溢出导致布局视口膨胀与点击坐标漂移

| 项 | 内容 |
|----|------|
| 级别 | 🟡 中（影响移动端可用性，非数据风险） |
| 现象 | Pixel 5 视口（CSS 宽度 393px）下 `window.innerWidth` 被撑大到 445px；页面整体被缩放，元素命中坐标与视觉位置不一致，城市弹窗关闭按钮 tap 持续超时失败 |
| 影响范围 | 移动端全站布局与所有依赖坐标命中的点击操作；Android 主流尺寸均复现 |
| 根因 | `main.css` 中 `html` / `body` 使用 `overflow-x: hidden`。该属性会创建滚动容器但**不阻止内容撑大初始包含块**，配合相册 3D `perspective` 布局与绝对定位装饰圆（`.circle`）超出视口，导致布局视口被放大 |
| 已采取措施 | 将 `html` / `body` 的 `overflow-x` 由 `hidden` 改为 `clip`（`clip` 不生成滚动容器、不参与视口撑大） |
| 修复效果 | Pixel 5 / iPhone 12 / 桌面三端首页与弹窗打开后 `scrollWidth == innerWidth`（溢出量 0）；相册 3D 卡片坐标未偏移；城市弹窗关闭按钮 click 成功；`mobile-responsive` 原 2 条失败用例转为通过，三端回归无新增失败 |

### 5.2 待决策：`public/data/data.db` 可经 HTTP 直链下载（信息泄露）

| 项 | 内容 |
|----|------|
| 级别 | 🔴 高（数据库文件可被匿名下载） |
| 现象 | 请求 `GET /data/data.db` 返回 200 且响应体为完整 SQLite 数据库文件 |
| 影响范围 | 任何可访问站点者均可下载整库，包含演唱会、城市、许愿、点赞等业务数据 |
| 根因 | 数据库文件存放于 `public/` 静态目录，Nitro 默认将 `public/**` 全量作为静态资源对外提供 |
| 已采取措施 | **未擅自修改**（涉及部署与数据路径调整，影响面超出测试修复范围）；已在 `security.spec.ts` 中以 `test.fail` 登记该用例，缺陷修复后用例会以「意外通过（XPASS）」暴露，提示同步更新断言 |
| 后续行动（建议） | 二选一：① 将数据库文件移出 `public/`（如 `server/data/`）；② 通过 Nitro `routeRules` / 中间件拦截 `/data/*.db` 的直链请求返回 404。修复后需回归 `security.spec.ts` 并重跑全量 E2E（负责人与时间节点待定） |

### 5.3 观察项：返回顶部按钮与页脚层级

- 现象：早期记录中，滚动至页面底部时 `#backToTop` 存在被页脚内容覆盖的疑似遮挡。
- 复核结果：**当前已不复现**。在 Pixel 5 与桌面 1440px 下分别于页面中部、贴近页脚（92%）、页面底部三处做 hit-test，命中元素均为按钮自身（`button#backToTop` / 其图标），按钮 `opacity: 1` 且可正常点击。
- 处置：作为回归观察项保留，无需当前修复。

## 六、测试数据与环境保护

| 措施 | 说明 |
|------|------|
| 数据库隔离 | E2E 全程注入 `NUXT_TURSO_DATABASE_URL` 指向系统临时目录下的 fixture 库（默认 `%TEMP%\ilive-e2e\e2e-data.db`），由 `seed-e2e-db.mjs` 按 schema 确定性重建（含恶意用例数据），**不读写 `public/data/data.db`** |
| 项目分流 | `chromium-desktop`（排除移动端用例文件）与 `chromium-mobile`（Pixel 5，`isMobile` + `hasTouch`，仅移动端用例）两个 project，避免移动端用例在桌面环境误跑 |
| 串行稳定 | `workers: 1` + `fullyParallel: false`，规避共享 fixture 库的写竞争；不与 vitest 并行执行 |
| 噪声屏蔽 | 全局 launchOptions 注入 `--autoplay-policy=no-user-gesture-required`，消除背景音乐 `play()` 被拦截产生的控制台噪声 |
| 假失败预防 | 写用例前先核对真实选择器与 `public/` 下静态资源路径存在性，避免选择器臆测与资源 404 造成的误报 |
| 产物归档 | 原始结果 `test/report/e2e-playwright.json`、HTML 报告 `test/report/e2e-html/`、失败现场附件 `test/report/e2e-artifacts/` |
